# KNN Classification Project

A comprehensive demonstration of the K-Nearest Neighbors algorithm applied to an anonymized dataset.

## Dataset
The dataset (`KNN_Project_Data`) involves continuous features that have been scaled or anonymized, paired with a target class.

## Objective
To perform a complete machine learning lifecycle utilizing KNN on a standard dataset, predicting the target class efficiently.

## Methodology
The `knn_project.ipynb` encompasses exploratory data analysis, data scaling, training the KNN model, evaluating predictions, and choosing the optimal 'k' value to reduce error rates.
