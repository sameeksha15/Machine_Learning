# Iris Species Classification (KNN)

A classic machine learning project that uses the K-Nearest Neighbors algorithm to classify Iris flowers into three species.

## Dataset
The Iris dataset (`Iris.csv`) contains measurements of sepal length, sepal width, petal length, and petal width for three species: Setosa, Versicolor, and Virginica.

## Objective
To correctly categorize Iris flowers into their respective species based on their physical dimensions.

## Methodology
The `KNN Iris.ipynb` notebook demonstrates a foundational workflow: loading data, visualization, scaling features, training a KNN model, and using the elbow method to ascertain the optimal 'k' value.
