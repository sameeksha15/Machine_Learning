# Credit Card Fraud Detection (KNN)

This project utilizes the K-Nearest Neighbors (KNN) algorithm to detect fraudulent credit card transactions.

## Dataset
The dataset (`card_transdata.csv`) encompasses varied features of credit card transactions, which indicate factors such as distance from home, distance from last transaction, ratio to median purchase price, and whether the transaction was done via PIN or chip.

## Objective
To accurately identify fraudulent transactions from legitimate ones to minimize financial risk and enhance transaction security.

## Methodology
The steps detailed in `Credit_card.ipynb` include data analysis, scaling distance and pricing metrics, addressing potential class imbalance, model training with KNN, and rigorous evaluation using confusion matrices and accuracy scores.
