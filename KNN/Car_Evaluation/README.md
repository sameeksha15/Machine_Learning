# Car Evaluation Classification (KNN)

This project applies the K-Nearest Neighbors (KNN) algorithm to evaluate and classify cars based on their structural and economic attributes.

## Dataset
The dataset (`car_evaluation.csv`) contains categorical attributes concerning the buying price, maintenance cost, number of doors, capacity, luggage boot size, and estimated safety of cars.

## Objective
To classify cars into discrete categories of acceptability using the KNN algorithm, evaluating the model's performance on categorical feature spaces.

## Methodology
The Jupyter Notebook (`Car_Evaluation.ipynb`) outlines the process of encoding categorical variables, scaling, splitting the data, training the KNN classifier, and evaluating its accuracy and classification report.
