# Wine Quality Classification (Random Forest)

This project models wine physicochemical properties against quality ratings using a Random Forest Classifier.

## Dataset
The dataset (`wine.csv`) tracks parameters such as alcohol percentage, density, sulphates, and acidity corresponding to sensory quality scores.

## Objective
To construct a highly accurate, robust classification model leveraging the Random Forest algorithm to evaluate wine quality systematically.

## Methodology
The `Wine_Quality_RFC.ipynb` notebook details data preparation, hyperparameter tuning of the Random Forest model, and analysis of feature significance to establish which chemical traits most heavily impact final wine quality ratings.
