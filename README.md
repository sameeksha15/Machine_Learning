# Machine Learning Projects Repository

This repository contains a collection of Machine Learning projects implemented in Python using Jupyter Notebooks. The projects are categorized by the underlying algorithm used for analysis and prediction, providing a structured approach to understanding various machine learning techniques.

## Repository Structure

- **Energy_Efficiency**: Projects focused on predicting building energy efficiency parameters.
- **KNN (K-Nearest Neighbors)**: Various classification tasks including Car Evaluation, Credit Card fraud detection, Fake Bills identification, and Iris species classification.
- **Logistic_Regression**: Classification problems approached with Logistic Regression, including Banking Scheme churn/conversion, Iris species, Titanic survival, and Wine Quality.
- **Random_Forest_Classifier**: Implementations of Random Forest for enhanced predictive accuracy on Banking data and Wine Quality.

Each subdirectory contains the dataset, the Jupyter Notebook with the code, and a dedicated README with context about the project.

## Requirements
- Python 3.x
- Jupyter Notebook
- pandas, numpy, scikit-learn, matplotlib, seaborn
