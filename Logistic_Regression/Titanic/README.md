# Titanic Survival Prediction (Logistic Regression)

This project applies Logistic Regression to the famous Titanic dataset to predict passenger survival.

## Dataset
The dataset (`titanic_train.csv`) features passenger information including age, sex, passenger class, ticket fare, and cabin details.

## Objective
To predict whether a given passenger survived the Titanic disaster based on socio-economic status, demographic profile, and travel circumstances.

## Methodology
The analysis in `Titanic.ipynb` emphasizes robust data cleaning strategies, specifically handling missing values for age and cabin, creating dummy variables for categorical data, and fitting a Logistic Regression model to classify survival accurately.
