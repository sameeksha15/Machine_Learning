# Iris Species Classification (Logistic Regression)

This project implements Logistic Regression to categorize Iris flower species.

## Dataset
The widely recognized Iris dataset (`Iris.csv`) includes sepal and petal dimensions for three specific types of Iris flowers.

## Objective
To develop a multiclass Logistic Regression model that classifies the Iris flowers with high accuracy based on their measurements.

## Methodology
The workflow present in `Iris.ipynb` involves loading the dataset, feature visualization, model training using multinomial logistic regression, and performance validation via classification metrics.
