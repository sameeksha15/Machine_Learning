# Wine Quality Classification (Logistic Regression)

This project assesses wine quality attributes to classify it into respective quality tiers using Logistic Regression.

## Dataset
The dataset (`wine.csv`) encapsulates physicochemical tests on wines, including features like acidity, residual sugar, chlorides, pH, and alcohol content, alongside a quality rating.

## Objective
To determine wine quality based solely on chemical properties, formulating a classification framework.

## Methodology
In `Wine Quality.ipynb`, the features are scaled, collinearity is assessed, and Logistic Regression is applied. The project evaluates the model's proficiency in distinguishing between distinct quality thresholds.
